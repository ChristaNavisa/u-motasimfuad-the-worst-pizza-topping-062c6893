Entry for [The Worst Pizza Topping](https://make.fun/bounty/u-motasimfuad-the-worst-pizza-topping-062c6893) on make.fun.

The program writes one line to `/output/entry.txt`: a pitch for the worst pizza topping imaginable — wet socks on a pizza — so awful that the crust files a complaint before the eater does. The gate requires under 200 characters of UTF-8 text on one line; this entry is 74 characters on one line, no trailing newline.

> This pizza comes topped with wet socks. The crust filed a complaint first.

The joke is the reversal at the end: the topping is so bad the pizza itself objects to it.

Run with Node 22+:

```sh
node main.ts
```
